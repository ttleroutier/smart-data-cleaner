# smart-data-cleaner
Ce projet propose un outil no-code destiné à automatiser et démocratiser les tâches répétitives de nettoyage de données. Il vise à réduire le temps consacré à la préparation des datasets, à améliorer leur qualité, et à rendre la data science accessible aux utilisateurs non techniques.

# Smart Data Cleaner

Clean your data in 3 clicks, no code required.

## Features
- Upload CSV or Excel files
- Automatic data diagnostics
- One-click cleaning actions
- Download cleaned dataset
